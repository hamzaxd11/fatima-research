## Main Finding

The final analysis included **120 valid participants**.

- Practice scores differed significantly across maternal-education groups in the primary unadjusted analysis; a conservative exploratory Holm sensitivity correction attenuated the evidence.
- The omnibus knowledge-score comparison was not statistically significant; an exploratory ordinal trend was statistically significant.
- The effects were small, age may confound the group result, and some education groups had very few participants.

## Repository Layout

- `comparative_study/` contains downloaded papers, full-text evidence, metadata, comparison outputs, and audits.
- `docs/analysis/` contains statistical methods and result summaries.
- `docs/verification/` contains manuscript, reference, and integrity checks.
- `docs/technical/` contains developer and pipeline documentation.
- `figures/` contains manuscript-ready figures.
- `output/analysis_20260712_224950/` is the only retained, corrected final analysis bundle.

Participant-level scored CSV files are local analysis artifacts and are excluded from new commits. Public release requires a separate disclosure-control and ethics review.
