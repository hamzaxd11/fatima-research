# Menstrual Hygiene Research Project

This repository contains the final research paper, statistical analysis, and supporting documents for a study of menstrual hygiene knowledge and practices among adolescent girls in sub-urban Lahore, Pakistan.

## Main Finding

The final analysis included **120 valid participants**.

- Maternal education was linked to a statistically significant difference in **menstrual hygiene practice scores**.
- Maternal education was **not** linked to a statistically significant difference in **knowledge scores**.
- The observed effects were small and should be interpreted carefully, especially because some education groups had very few participants.
